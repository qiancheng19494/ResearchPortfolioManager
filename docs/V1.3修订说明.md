# V1.3 修订说明

修订日期：2026-10-17（Asia/Shanghai）。从 V1.2 建立独立 V1.3 副本，历史目录、ZIP、提交和发布保留；测试仅使用临时或隔离合成资料。

## 修改与原因

| 问题或功能 | 本轮处理 | 预期验证 |
| --- | --- | --- |
| 受管理目录通过 Windows 目录联接落到另一实际位置，导出目标保护不一致 | 按实际路径统一比较受保护目录和目标，拒绝写入受保护位置 | 目录联接与普通目录、CSV/HTML/备份/报告目标、原文件保持 |
| Windows 材料路径名称及文件别名检查不足 | 拒绝设备名、尾点/尾空格、重解析点和硬链接等不安全材料路径 | 导入、预览、备份和恢复拒绝非法路径；正常旧备份仍可恢复 |
| 材料类别/版本空值可能保存成文字 | 服务校验非空文本；新建与编辑不把 `None` 转文字 | 显式空值、空白、非法类型不产生成功记录，正常值可保存 |
| CSV/HTML 失败后仍显示上次成功结果 | 新作业清除旧成功路径与提示，失败保持明确失败状态 | 先成功再失败、成功位置按钮与提示一致 |
| 配置保存复用固定临时文件名 | 独占随机临时文件，flush/fsync 后原子替换，失败保留旧配置及内存，只清理本次临时文件 | 原临时名称哨兵和真实硬链接保持、替换/序列化失败 |
| 新增材料完整性体检 | 原材料页后台只读检查活跃与归档全部材料，显示异常并导出 JSON | 正常、缺失、大小/哈希变化、路径异常、只读与主线程交互 |

本版不宣称所有缺陷均已排除，也不将本地路径保护问题描述为未经证实的远程攻击。具体实现文件及回归入口见 [功能与代码对应表](功能与代码对应表.md)。

## 兼容与保护

六页、schema 1 和备份格式 1 不变；不重建数据库、不更新旧哈希、不静默替换旧版本、不猜测历史负责人。归档只读仍允许检查材料；体检不改变项目、材料记录、受管理文件或配置。检查结果仅对应执行时状态。

独立预览先核对原副本大小和 SHA-256；需要保留编辑时另存并导入新版本。损坏或缺失材料必须由有效备份或可信原文件恢复，报告不能凭哈希重建文件。第三方说明保留。
