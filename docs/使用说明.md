# V1.3 使用说明

## 启动与资料目录

安装版从快捷方式启动，便携版解压后运行 `ResearchPortfolioManager.exe`；源码安装依赖后运行 `main.py` 或 `run.ps1`，具体命令见 README。源码默认 `user_data/`，冻结程序默认 `%LOCALAPPDATA%\ResearchPortfolioManager\user_data`。状态栏显示实际目录；`--data-dir` 用于指定独立位置。不同目录的数据独立，切换版本不等于切换资料库。

“个人资料与设置”可修改姓名、背景和研究兴趣。姓名影响以后新建项目的默认负责人，不批量改写旧项目。配置 `name` 必须为非空文本，`background/interests` 必须为文本，`demo` 必须为布尔值。非法配置指出字段并保留原文件；按提示修正 `config/settings.json` 后重开。字符串 `"false"` 不能代替布尔值。

用 `--data-dir demo_data` 打开独立演示。黄色“演示数据”标记表示合成资料；真实默认资料为空且 `demo=false`。关于窗口显示软件名称、版本及功能说明。

设置保存使用独立临时文件，完整写入后替换；失败保留上次配置，不把未保存修改显示为成功。不会复用或清除不属于本次保存的固定临时文件。

## 日期与概览

日期输入格式为 `YYYY-MM-DD`。点击“日历…”选中日期后，需点击“使用所选日期”才回填；取消或关闭不改变原值。点击“清空”后保存为空值，空日期不会自动变成今天。日期范围可单边留空；非法日期或起止逆序会被拒绝。归档只读限制同时作用于文本、日历和清空。

综合概览显示未归档项目、未完成任务、逾期任务，以及成果和材料总数。截止日期早于今天且未完成才逾期。无截止日期、已完成和归档项目任务不进入提醒；未来七天为明日至第七天。成果与材料统计包含保留的归档记录。点击记录可进入详情，必要时“刷新概览”。

## 项目管理

新建时填写名称、类别、简介、负责人、起止日期、状态与备注。负责人默认当前个人姓名，必须为非空文本；显式空串、空白或空值提示“负责人不能为空”，失败不保存。历史空负责人可进入编辑，填写后保存。开始日期不得晚于计划结束日期。

关键词、类别和状态可组合检索；重置清除条件，`%` 和 `_` 作为普通文字。选中行可编辑或查看关联详情。归档需确认，默认列表隐藏归档项目；勾选“包含已归档”后可查看或恢复。归档保留任务、成果和材料，相关记录只读，任务不再提醒。本版不物理删除项目。

## 任务管理

新增任务须选择未归档项目，填写标题、说明、可空截止日期、优先级与状态。列表支持关键词、项目、状态和到期快捷条件组合。“今天到期”“已逾期”“未来七天（明日至第七天）”只包含未完成且项目未归档的任务；无日期不进入到期结果。“全部到期情况”或重置恢复通常列表。

改为已完成时记录完成时间；保持完成状态编辑保留该时间，改回其他状态清除完成时间。删除需确认。归档项目的任务可查看，只读且不可删除。

## 成果台账

登记成果需选择项目，填写名称、类型、事实状态、相关日期、编号或链接、贡献说明和备注。论文、软件著作权、专利、竞赛成果及其他成果各有对应状态；类型变化时不兼容状态会重置。软件不自动确认成果真实性。

可按关键词、项目、类型、状态和日期范围筛选。查看证明材料可进入关联材料。成果删除需确认；仍有关联材料时拒绝删除，先在材料页解除成果关联，文件仍保留。归档项目成果只读。

## 材料归档

导入支持常见文档、图片和 ZIP，拒绝脚本及可执行文件。选择未归档项目，可关联该项目成果，填写类别、版本与备注。后台复制、计算并核对大小和 SHA-256，成功后保存记录；失败不形成成功记录。源文件保持原样。

正式副本位于 `materials/<UUID>/<原文件名>`；同名文件与不同版本独立保存。“导入新版本”建立新记录，不覆盖旧版本。“编辑信息 / 解除成果关联”只修改成果关联、类别、版本和备注，不移动项目或文件。

类别与版本必须为非空文本，空值或纯空白会被拒绝，备注必须为文本。受管理相对路径不允许 Windows 设备名称、尾点/尾空格、不安全字符、符号链接、重解析点或硬链接文件。遇到路径异常时不要通过修改数据库路径或旧哈希绕过检查，先核对可信原文件与备份。

“打开预览副本”和“打开预览目录”均先在后台核对正式副本，再复制到独立 `preview_cache/<UUID>/` 并复核，完成后在主线程打开默认关联程序。活跃和归档材料使用相同保护。预览编辑要保留时，请另存后导入新版本；归档项目须先恢复。预览不入备份，软件不强制关闭外部程序、不自动删除已暴露预览。

正式副本缺失、大小或哈希变化时，拒绝预览与完整备份，保留原记录及旧哈希。恢复需要损坏前有效备份或可信原文件，哈希不能重建字节。可信文件可作为新版本导入，不能伪装为旧版本。归档材料信息只读；本版不物理删除材料、不比较或合并版本。

点击“检查全部材料…”可在后台检查资料库中所有材料版本，包括已归档项目，不受当前材料列表筛选影响。结果窗口显示总数、一致数、异常数，以及每项材料的项目状态、版本和原因。单个材料异常不阻断后续检查；一致表示本次读取大小和 SHA-256 与原记录相符。

可点击“导出 JSON 检查报告…”保存本次结果，包含检查时间、材料标识、项目、版本、预期和实际大小/哈希及异常原因。报告可能包含项目名称和材料文件名，请按自己的资料公开范围保管。报告导出不改变正式材料、旧哈希或项目状态。它是执行时的检查结果，不保证文件此后不会变化；检查失败或异常不会自动修复文件。

## 导出、备份与恢复

成果 CSV 可按项目、类型和状态筛选，页面显示实际筛选条件。CSV 使用 UTF-8 BOM，公式开头文字在导出值中保护，数据库原值不变。项目 HTML 包含简介、备注、任务、成果和材料目录，用户文字转义，可用浏览器打开。

CSV、HTML、完整备份及体检报告的保存位置不能覆盖数据库、配置、日志、预览缓存或受管理材料。目标保护使用实际目录位置，Windows 目录联接形成的路径别名同样检查。CSV/HTML 开始新作业先清除上次成功结果，失败不沿用旧成功路径。

创建完整 ZIP 备份时，后台暂停写入并生成一致数据库快照、材料、配置与校验清单。新作业先清除旧成功路径，失败不沿用上次成功结果。“打开保存位置”指向最近成功结果目录。正式材料或配置无效会使备份失败；日志、锁、导出、预览缓存和其他备份不递归打包。

恢复选择本软件完整 ZIP 和新建或空目录。程序检查清单、大小、SHA-256、数据库完整性/schema/外键、材料引用和路径安全，拒绝损坏、未知格式、危险路径及非空目标。不覆盖当前资料。

恢复成功后当前窗口仍使用原资料库。关闭软件，复制成功提示中的完整 PowerShell 命令，用恢复目录重开；源码也可运行：

```powershell
& .\.venv\Scripts\python.exe main.py --data-dir "恢复后的目录"
```

重开后核对状态栏目录、记录数量、材料和真实/演示标记。升级或恢复前保留可用备份，不手工解压覆盖正在使用的资料库。schema 和备份格式仍为 1，旧有效备份兼容的本轮结果见验证报告。

## 故障与限制

失败给出中文原因，日志位于当前资料根目录。后台作业期间禁用写操作，关闭需等待完成。目录被另一实例占用时关闭另一实例或换目录；配置错误和未知数据库版本不会静默重建。预览可能累计占用空间，确认外部程序关闭后再自行清理。未验证项目见本轮验收清单。
