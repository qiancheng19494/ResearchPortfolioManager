# V1.0 使用说明

## 首次运行与个人资料

按 README 安装依赖并运行 `main.py` 或 `run.ps1`。默认 `user_data` 首次为空。点击左侧“个人资料与设置”可修改姓名、学习背景和研究兴趣；保存到当前资料目录。姓名影响以后新建项目的默认负责人，原有项目负责人不自动改写。资料目录在状态栏显示。不同目录保存独立的数据和配置。

“关于软件”展示软件名称、版本、功能和第三方依赖说明，不提供认证或登记编号，也不预设著作权人。学校信息只表示个人学习背景。

本目录为 Reviewed 修订交付，界面版本仍为 V1.0。配置读取、设置保存、备份和恢复使用相同校验：姓名必须为非空文本；背景和兴趣必须为文本；演示标记必须是真正的布尔值。允许缺省字段，合并默认值后校验。非法配置会指出具体字段并保留原文件，不静默覆盖或转换字符串 `"false"`。出现该提示时，保留资料目录，按提示修正 `config/settings.json` 后再启动。

演示用 `--data-dir demo_data` 启动，界面黄色提示“演示数据”。请勿将演示日期、成果状态或材料当作本人履历。默认真实目录仍独立为空。

## 综合概览

首页从当前数据库显示未归档项目、未完成任务、逾期任务、成果和材料版本总数，分别列出今天到期、逾期、明日至第七天到期以及最近更新项目。点击记录可进入对应任务或项目详情。

截止日期早于今天且未完成才算逾期。无截止日期、已完成任务和归档项目任务不进入提醒。成果与材料总数包含保留的归档记录。无数据时显示零和“暂无记录”；需要时点击“刷新概览”。

## 项目管理

1. 点击“新建项目”，填写名称、类别、简介、负责人、开始日期、计划结束日期、状态和备注，点击“保存”。负责人默认为当前个人姓名，必须填写非空文本；显式空字符串、空白和空值均提示“负责人不能为空”，失败不保存。开始日期不得晚于结束日期。
2. 用关键词、类别和状态筛选，点击“检索”。“重置”清除条件。关键词按文本匹配，`%` 和 `_` 作为文字，不当作通配符。
3. 选中一行后“编辑”修改；“查看关联详情”或双击行查看项目及任务、成果、材料。详情的关联任务/成果可进入对应详情，材料经校验后通过默认程序打开隔离预览副本。历史空负责人记录可以进入编辑，填写真实负责人后才能保存。
4. 选中项目后“归档项目”，阅读确认再执行。项目在默认列表隐藏；勾选“包含已归档”可找到。归档保留关联记录和材料，只允许查看，任务不再提醒。选中已归档项目后按钮显示“恢复项目”，确认后恢复编辑能力。

本版不物理删除项目。表格可拖动列宽、滚动、点击表头排序；长文本可查看提示或详情。

## 任务管理

点击“新增任务”，选择一个未归档项目，填写标题、说明、可空截止日期、低/中/高优先级和待办/进行中/已完成状态。任务必须关联存在的项目。列表支持关键词、项目和状态筛选，提醒列显示今天到期、逾期或项目已归档。

选中行点击“编辑 / 查看”或双击。改为已完成会记录完成时间；保持完成状态编辑时保留该时间；改回待办或进行中清除完成时间。删除须确认，只删除该任务。归档项目的任务可查，但详情只读，删除不可用。

## 成果台账

点击“登记成果”，选择项目并填写名称、类型、事实状态、相关日期、编号或链接、贡献说明和备注。类型有论文、软件著作权、专利、竞赛成果和其他成果。状态选项随类型改变；原状态不兼容时重置为该类型的第一个状态。请根据可靠材料选择，软件不自动查询或确认真实性。

按关键词、项目、类型、状态、相关日期起止范围检索。空范围不限制日期，范围必须合法且起点不晚于终点。选中行“编辑 / 查看”修改；“查看证明材料”或双击行可看成果及关联材料。

删除成果需确认。若有关联材料，软件拒绝删除；先到材料页编辑信息，将“关联成果”改为“不关联成果”并保存，然后再删除。解除关联不会删除文件。归档项目的成果只读。

## 材料归档

1. 点击“导入材料”，选择 PDF、DOCX、XLSX、CSV、TXT、PNG、JPG、ZIP 等允许文件。选择未归档项目，可额外选择该项目下的一项成果，填写材料类别、版本标签和备注。
2. 点击保存后后台复制文件、计算并核对 SHA-256，显示处理状态。等待成功提示。源文件保持原样；复制或校验失败会提示原因，失败不会形成成功记录。
3. 保存副本位于当前资料根目录 `materials/<UUID>/<原文件名>`。同名材料和不同版本独立保存。选中记录点击“导入新版本”，选择新文件及新标签，不覆盖旧记录。
4. 用项目、成果、类别和关键词筛选。“编辑信息 / 解除成果关联”只能改变成果关联、类别、版本和备注，不移动所属项目和文件。
5. 选中材料可以“打开预览副本”“打开预览目录”或“校验 SHA-256”。两个预览入口均先在后台核对受管理副本的大小和 SHA-256，再复制到独立的 `preview_cache/<UUID>/` 目录并核对副本；完成后由主线程调用 Windows 系统默认关联程序。ZIP 内容不自动执行。活跃项目和归档项目均使用该保护方式。
6. 外部编辑器修改并保存的是预览副本，不改变归档原副本、原哈希和原版本。若要保留修改，请先另存到自己选择的位置，再使用现有“导入新版本”；归档项目须先恢复项目才能导入。预览文件不进入完整备份，软件不强制关闭外部编辑器、不自动清理已打开的预览文件。
7. 受管理副本缺失或大小/哈希变化会明确报错，原记录保留，不能打开或生成完整备份。旧哈希只能校验，不能重建损坏字节；恢复须依赖损坏前有效备份，恢复到新目录后重启核对。没有有效备份时，可找到可信原文件后作为新版本重新导入，不能把修改后的内容伪装成旧版。

归档材料可读与校验，信息只读。脚本与可执行文件不允许导入。本版不提供材料物理删除、自动清理、版本比较或合并。

## 报告与备份

成果 CSV：选择项目、成果类型和状态，查看页面显示的完整筛选条件，点击“导出成果台账 CSV…”，选择保存位置。成功后显示路径和实际筛选条件。CSV 使用 UTF-8 BOM，公式开头文字在导出副本中加前缀，数据库原值不变。

项目 HTML：选择一个项目后点击“导出所选项目摘要 HTML…”。摘要包含该项目简介、备注、任务、成果和材料目录，用户文字被转义。报告仅显示实际保存记录；可用浏览器查看，没有 Word/PDF 自动排版或申请材料生成功能。

完整备份：点击“创建完整 ZIP 备份…”，选择保存位置。后台期间写入暂停，完成后显示成功位置。缺失或被改动的材料会使备份失败；日志、锁、导出文件及其他备份不会递归打包。“打开保存位置”可打开最近结果的目录。

预览缓存也不进入备份。仅修改预览副本不影响正式材料哈希，可正常完整备份并恢复。配置同样要符合统一类型规则，否则备份或恢复会指出字段并失败，原配置保留。修订版继续支持符合原 V1.0 格式与校验规则的有效 ZIP 备份。

验证恢复：点击“恢复到新的资料目录…”，选择本软件完整备份 ZIP，再选择新建/空文件夹，确认。程序先验证备份格式、文件清单、SHA-256、数据库 schema/外键及材料引用。损坏、危险路径、未知格式和非空目录均被拒绝，不覆盖当前资料。

恢复成功后当前窗口仍使用原资料库。优先复制恢复成功框里显示的完整 PowerShell 命令，它使用本次运行的 Python 环境。也可关闭软件，在项目目录运行：

```powershell
& ..\..\work\v\Scripts\python.exe main.py --data-dir "恢复后的目录"
```

重新打开后查看记录和材料，必要时点击“校验 SHA-256”再打开附件。不要自行用 ZIP 解压覆盖正在使用的 `user_data`。

## 故障处理

操作失败会给中文原因并写入当前资料根目录日志。后台任务期间界面禁用会修改数据的操作，关闭需等待完成。资料目录被另一实例占用时换目录或关闭另一实例。配置错误、未知数据库版本不会静默重建覆盖。首次依赖安装的路径长度问题及启动方法见 README。
