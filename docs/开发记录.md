# V1.0 开发记录

日期使用用户所在时区 Asia/Shanghai：2026-10-10。此文档记录本次实际工具开发过程，不声称存在此前人工开发、合作或登记历史。

以下第 1—10 项是原版开发批次记录，不作为 Reviewed 修订版本轮复跑证据。`docs/test-results.txt` 在原始私有交付中保留该批次输出，本公开副本仅保留经本机路径脱敏的文字；本轮结果另记在验证报告和修订说明。用户随后报告独立复跑的 40 项非 GUI 测试全部通过，该结果仅注明为用户提供的信息。

1. 检查项目工作区，没有发现需要接续的同名应用源码。交付项目建立于当前工作区 `outputs/ResearchPortfolioManager`；中间文件放在 `work/`，未搜索、复制或更改用户其他项目与科研资料。
2. 确认可用 Python 3.11.9。先尝试项目深目录虚拟环境安装 PySide6，出现 Windows 路径长度限制；随后改用较短的工作区 `work/v` 专用环境，安装并固定 PySide6 6.10.3。失败环境移至 `work/failed-runtime`，不列入交付源码。
3. 基于需求确定六页、单用户 SQLite、UUID 材料隔离、归档只读及固定日期可测的提醒。先编写内部接口约定，然后分别实现数据/业务、界面、材料/导出/备份、测试/演示/文档，避免多模块同时改写同一文件。
4. 数据层实现版本检查、外键、枚举 CHECK、复合关联外键、归档触发器、禁止项目/材料删除、独立线程连接和事务。配置采用临时文件替换，入口使用 Qt 进程锁。
5. 材料服务采用先复制和哈希确认再提交记录；ZIP 备份使用 SQLite backup API 与完整 manifest，恢复先在临时目录验证并只接受新建/空目标。
6. 测试与演示程序均使用独立目录；首次真实资料库保持为空，演示仅生成 TXT，并醒目标注“演示数据”。

7. 核心测试发现 Windows 对只读文件句柄 fsync 出现 EBADF；改为读写句柄同步，随后材料与完整流程通过。测试初稿直接 SQLite 连接未关闭导致 Windows 清理失败，改为显式关闭。GUI 主线程回调、概览单击入口和缺失文件提示经过实际操作验证。
8. 最终完整测试 43 项全部通过（30.082 秒）；入口两次真实启动关闭均返回 0；默认真实库仍空，演示独立含 2 项目/4 任务/2 其他成果/4 TXT 材料版本。真实运行界面保存于 `docs/screenshots/`，并查看主要页面确认 1366×768 布局可操作。
9. 默认配置最终统一实际读取 `config/defaults.json`；初始化和配置重开两项定向检查通过。整理使用、设计、验证、功能对应和依赖说明，没有新增第二版功能或登记材料。
10. 最后复核恢复提示，修正通用 `python` 可能指向其他环境的问题，改为当前运行环境生成的完整 PowerShell 命令；小材料显示实际字节。原生 GUI 完整流程定向再测通过（24.809 秒），更新截图。

实际运行边界、修复与最终结果见 [验证报告](验证报告.md)。未执行的测试没有记录为通过。

## V1.0 首版修订（Reviewed）记录

修订工作日期：2026-10-10（Asia/Shanghai）。本轮仅处理用户确认的三项问题，软件名称、版本、六页导航和首版范围保持不变。

1. 先检查实际源码、原有文档和运行环境，在 `outputs/ResearchPortfolioManager_V1.0_Reviewed` 创建独立修订副本。复制源码、模板、资源、测试、文档和独立演示；排除真实 `user_data`、依赖环境、日志、预览缓存和测试临时文件，保留原目录和原 ZIP。原版保留校验及本轮实际验证证据见验证报告。
2. 复核材料打开调用路径：原版把 `materials/` 受管理路径交给默认关联程序，编辑器可能保存覆盖原副本；归档数据库只读并不阻止外部文件改写。本轮改为先后台校验大小/哈希并生成 UUID 隔离预览，再在主线程调用系统默认程序；目录入口改为预览目录。交给外部程序的预览不自动清理，不强制终止编辑器；保留修改需另存后导入新版本。损坏副本不能由哈希重建，错误提示明确恢复条件。
3. 负责人在项目表单和服务层统一必填。显式空字符串、空白、`None` 及非文本值失败；未提供字段时才使用经过校验的配置姓名。不更新数据库结构，不猜测、批量补写历史负责人；旧空记录仍可编辑，填实后保存。
4. 增加共用 `validate_config`，默认配置、已有配置读取、设置保存、备份和恢复合并缺省值后使用同一规则。错误明确到 `name/background/interests/demo` 字段，原文件保留；字符串布尔值不强制转换。缺省字段读入时只在内存补全。
5. 保留 SQLite schema 版本 1、建表语句、索引、触发器和严格恢复结构检查；对原 V1.0 实际生成的有效备份进行修订版恢复验证，不以新代码自己生成的包替代旧版兼容证据。
6. 新增回归先运行，再复跑原有完整测试，完成隔离六页流程。预览编辑采用捕获实际关联调用目标后的写入模拟；真实系统调用与外部应用检查另行区分。本轮精确数量、失败/跳过和界面检查以验证报告为准，不用原 43 项结果替代。
7. 更新受影响文档及真实窗口截图，打包排除真实资料、依赖、日志、预览缓存与测试临时文件。修订 ZIP 与交付目录逐文件校验，ZIP 的 SHA-256 在旁置校验文件记录，避免包内校验自身。
