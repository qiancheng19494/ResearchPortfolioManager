# V1.0 内部接口约定

数据库入口 `database.store.Store(data_dir)`；`root: Path`、`db_path: Path`、`connect()` 返回新的启用外键的 sqlite3 连接（Row 工厂），`write_lock` 为 RLock，所有写服务用该锁。每次操作自行开启/关闭连接，不跨线程复用。`config` 是字典；`save_config(dict)` 原子保存。`schema_version=1`。

Reviewed 共用 `database.store.validate_config(values, defaults=None)`：合并缺省值后要求 name 非空字符串、background/interests 字符串、demo 布尔值，错误指出字段；读取/保存/备份/恢复不转换错误类型。`save_project` 的 leader 显式空/空白/None 拒绝；缺省字段才使用已校验配置 name，不自动补写历史。

`services.portfolio.PortfolioService(store)`：
- `save_project(data, project_id=None) -> int`; `get_project(id) -> dict`; `list_projects(keyword='', category='', status='', include_archived=False) -> list[dict]`; `archive_project(id, archived=True)`。
- `save_task(data, task_id=None) -> int`; `get_task(id)`; `list_tasks(keyword='', project_id=None, status='', active_only=False)`; `delete_task(id)`。
- `save_achievement(data, achievement_id=None) -> int`; `get_achievement(id)`; `list_achievements(keyword='', project_id=None, type='', status='', date_from='', date_to='')`; `delete_achievement(id)`。
- `dashboard(today=None) -> dict`：键 `projects_count,tasks_count,overdue_count,achievements_count,materials_count,today_tasks,upcoming_tasks,overdue_tasks,recent_projects`。today 可传 date 或 ISO 字符串；未来七天为明日至第七天。
- `require_project(id, writable=False)`；归档时 writable 拒绝。`project_detail(id)` 返回 `project,tasks,achievements,materials`。

字段：projects `id,name,category,description,leader,start_date,end_date,status,notes,archived,created_at,updated_at`；tasks `id,project_id,title,description,due_date,priority,status,completed_at,created_at,updated_at`；achievements `id,project_id,name,type,status,related_date,reference,contribution,notes,created_at,updated_at`；materials `id` UUID 字符串，`project_id` 必需、`achievement_id` 可空，`original_name,category,version_label,notes,size,sha256,imported_at,relative_path`。列表额外提供 `project_name,project_archived`，materials 另有 `achievement_name`。空日期存 NULL。日期 YYYY-MM-DD，时间本地 ISO 秒。

常量 `services.portfolio.PROJECT_CATEGORIES, PROJECT_STATUSES, TASK_STATUSES, PRIORITIES, ACHIEVEMENT_STATUSES`（字典，key 论文/软件著作权/专利/竞赛成果/其他成果）。业务错误 ValueError 或明确异常。

`services.materials.MaterialService(store)`：`import_file(source, project_id, achievement_id=None, category='其他', version_label='V1', notes='') -> str`; `list_materials(keyword='',project_id=None,achievement_id=None,category='')`; `get_material(id)`；`file_path(id, verify=False) -> Path`（不存在明确报错，verify 校验）；`update_material(id, achievement_id=None, category='其他', version_label='V1', notes='')`，不得更改项目或受管理文件。选择文件允许常见文档图片ZIP，禁止脚本/可执行文件。

Reviewed `prepare_preview(material_id) -> Path` 必须由后台任务调用：核对原大小/SHA-256，创建 `preview_cache/<UUID>/` 独立副本并复核；失败只清理本次未暴露副本。主线程打开返回的预览路径或父目录，不将 `file_path` 的受管理路径交给关联程序。已暴露预览不自动清理，缓存不入备份。

`services.export_backup.ExportBackupService(store)`：`export_csv(destination, project_id=None, type='', status='') -> Path`; `export_html(destination, project_id) -> Path`; `backup(destination) -> Path`; `restore(archive,target) -> Path`。后台线程调用这些方法。备份共享写锁；恢复只允许新建/空目录，不改当前目录。

GUI `app.main_window.MainWindow(store)`，六个页面，引用服务。主入口负责 QApplication、QLockFile、日志。演示标志 config `demo: true`。

默认配置：name 示例用户；background 示例学校 / 示例专业 / 本科；interests 机器学习、数据挖掘与智能预测；demo false。不预设权利人或人工开发者。
