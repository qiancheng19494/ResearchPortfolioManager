## 数据与业务约束

SQLite schema 1 不变。本轮不修改表、索引、触发器或备份格式，不重建数据库。服务每次建立独立启用外键的连接，写入共用可重入锁与事务，不跨线程共享连接；SQL 值参数化。

表 `projects` 保存项目及归档标志，`tasks` 保存必需项目关联、状态和完成时间，`achievements` 保存项目、类型状态及事实信息，`materials` 保存 UUID、项目/可空成果关联、原文件名、大小、SHA-256 和相对路径。`schema_info` 保存版本。材料复合外键确保成果属于同一项目；成果有关联材料时拒绝删除。归档项目和关联数据由服务与触发器共同保护，只读；项目、材料不物理删除。

日期存 `YYYY-MM-DD`，空值为 NULL，时间为本地 ISO 秒。负责人要求字符串且去空白后非空，显式空值不转换为文字；仅缺省字段使用已验证配置姓名，不自动补写历史。配置默认、读取、保存、备份与恢复共用 `validate_config`，合并默认后验证 `name/background/interests/demo` 类型；错误指出字段，不覆盖原文件。配置保存使用临时文件原子替换。

## 日期和提醒

`NullableDateField` 保留文本接口与手工校验，日历显式确认才写回，取消不变，清空保持空文本。只读同时限制文本、日历、清空和快捷键。项目起止、任务截止、成果日期及成果范围共用控件，不增加存储字段。

提醒只包含未完成且项目未归档任务；早于今天为逾期，今天单列，明日至第七天为未来七天，空日期不进入提醒。概览与任务快捷筛选共用边界，快捷条件叠加关键词、项目和状态。全部范围恢复普通列表，不改变保存规则。

## 材料与预览

导入先检查项目/成果，建立 UUID 目录，计算源哈希，复制到临时文件，复核大小和哈希后转正式文件并提交记录；失败回滚本次记录并清理本次目录，源文件不改。每个版本独立记录，元数据编辑不改变项目和正式路径。

`prepare_preview` 检查正式副本存在性、大小和 SHA-256，建立 `preview_cache/<UUID>/` 副本再复核。后台完成后由主线程 `QDesktopServices.openUrl` 打开副本或父目录，正式材料路径不交给编辑器。已暴露预览不自动删除、不强制终止外部程序；预览不入备份。材料损坏保留旧记录与哈希，恢复需要有效备份或可信原文件。

## 导出与恢复

CSV 为 UTF-8 BOM，并对公式开头文本加保护前缀；HTML 转义用户文字。数据库原值不因导出变化。报告只包含实际记录，不自动生成成果事实。

完整备份在写锁下用 SQLite backup API 建立快照，打包受管理材料、配置和大小/SHA-256 清单，排除运行缓存等内容。恢复先在临时目录严格核对格式、清单、大小/哈希、数据库完整性/外键/schema、材料引用和安全路径，拒绝绝对路径、路径穿越、盘符、符号链接和未知内容。全部通过才写新建/空目标目录，不改当前资料库。

恢复后需按实际程序生成的命令用新目录重启。报告页以步骤、成功提示和可滚动结果解释当前目录与目标目录；新作业清除旧成功结果，失败不产生本次成功提示。V1.2 只整理版本与说明，以上规则保持。
