# V1.0 首版修订说明

修订日期：2026-10-10（Asia/Shanghai）。软件名称继续为“本科科研项目与成果档案管理系统 V1.0”；Reviewed 仅为交付标识。原目录 `outputs/ResearchPortfolioManager` 和原 `ResearchPortfolioManager_V1.0.zip` 保留，修订仅发生在 `outputs/ResearchPortfolioManager_V1.0_Reviewed`。

## 问题复现与修改

| 已确认问题 | 原代码隔离复现 | 修订措施 |
| --- | --- | --- |
| 打开材料可能覆盖归档原副本 | 捕获原版实际传给 `QDesktopServices.openUrl` 的路径，活跃和归档项目都指向 `materials/`；模拟编辑并保存该路径后，受管理字节改变，原源文件保持，随后完整备份因哈希校验失败拒绝 | 在后台核对大小/哈希并生成 UUID 隔离预览；主线程打开预览文件或预览目录，原路径不交给编辑器；原哈希与版本不变 |
| 负责人表单必填但服务放行 | 原服务将 `''` 和纯空白保存为空；将 `None` 保存成文字 `"None"` | 表单和服务拒绝显式空、空白、`None` 及非文本，统一提示“负责人不能为空”；仅字段缺省才使用已验证个人姓名 |
| 配置字段类型错误仍可读取 | 原版接受 `background=123`、`interests=[]`、`demo="false"`，界面布尔判断把字符串 `"false"` 当作演示真值 | 默认、读取、保存、备份、恢复统一调用 `validate_config`，先合并缺省值再校验具体字段，不转换字符串布尔值，保留错误原文件 |

复现由原版模块在独立临时资料中运行，不修改原版真实库。材料编辑步骤是对捕获路径的写入模拟，不声称已人工打开 Word 或其他编辑器保存。

## 修改位置及规则

| 文件 | 修改目的 |
| --- | --- |
| `services/materials.py` | `prepare_preview`：源大小/哈希、独立预览复制、复核和失败补偿；缺失/变化报错说明哈希无法重建 |
| `app/main_window.py` | `open_material`：后台校验/复制，主线程调用默认关联程序；拒绝时不启动，成功提示另存后导入新版本 |
| `app/pages.py` | 材料按钮/说明指向预览，目录入口不再引导编辑归档原文件 |
| `app/dialogs.py` | 项目负责人表单校验、历史空负责人编辑通路及材料预览说明 |
| `services/portfolio.py` | `save_project`：新建/编辑负责人一致必填，缺省才用有效配置姓名 |
| `database/store.py` | 共用 `validate_config`，默认模板/读取/保存规则一致，错误原文件保留 |
| `services/export_backup.py` | 备份/恢复配置同规则，预览缓存不打包，并保留严格原 V1.0 结构校验 |
| `tests/test_preview_regression.py` | 活跃/归档预览、实际 Qt 目标捕获、模拟保存、备份恢复、复制失败和原副本异常 |
| `tests/test_reviewed_validation.py` | 负责人新建/编辑/默认/历史空记录；配置非法重启、原字节保留、正常保存重开和真布尔标记 |
| `tests/test_reviewed_compatibility.py` | 独立进程用原 V1.0 模块生成有效备份，修订版恢复；schema、关联、记录、材料哈希、配置完全核对 |
| `tests/test_reviewed_flow.py` | 3 项原生 Windows 六页/表单/重开流程，活跃与归档预览、CSV/HTML、修订和原版备份界面恢复 |
| `tests/test_gui.py` | 原有测试为后台预览补充等待，并仅保存受影响材料页截图，其他截图字节保持 |

受管理原副本、数据库哈希和版本信息不因预览而变。每次预览使用资料根目录 `preview_cache/<UUID>/`，该缓存不进入完整备份或交付包。已交给程序的预览不自动删除，也不强制终止外部编辑器；保留修改须另存后“导入新版本”，归档项目须先恢复项目再导入。只清理本次失败且尚未交出的临时预览，不触碰先前已打开的预览。

原归档副本损坏或缺失时明确失败。SHA-256 不能重建损坏文件；须有损坏前有效备份，恢复到新的资料目录后重启核对；也可找到可信原文件后新建版本，不能改写旧哈希掩盖问题。

负责人不批量补写历史值；历史空值可进入编辑，由本人填写后保存。配置错误不回落并覆盖默认，不把 `None`、数字或字符串布尔值强制转换。

## 兼容性与验证证据

SQLite schema 版本仍为 1，建表、索引与触发器未改变。原有六页、成果状态、归档只读、版本隔离、CSV/HTML、安全 ZIP 备份恢复均保留。旧版兼容验证使用原版源码实际生成的包，未以修订版自生成包冒充旧版备份。

本轮新增回归、原有完整测试、界面流程、旧版恢复、失败/跳过和系统调用边界见 [验证报告](验证报告.md)。原开发批次的 43 项、后续 2 项与 1 项保留为历史；用户提供的 40 项非 GUI 复跑单独标为用户报告。本轮不借用这些数字作为新验证结论。

最终新增 32 项先执行（43.705 秒），原有完整 43 项后执行（27.874 秒），**75 个不同用例全部通过，失败 0、跳过 0**。初次原生流程 6 项有 1 次测试假设断言失败，已保留原始输出并修正为检查归档只读详情，随后原生 3 项和最终整批通过。另有 3 次真实默认关联 Qt API 调用返回 true，目标均为预览且原材料保持；外部应用窗口和真实编辑保存仍未观察，不能混同路径模拟回归。

含原 ZIP 的 69 项原版基线哈希全相同；schema 精确不变。修订目录无真实资料，演示标记和材料哈希只读检查通过。只有材料页原截图被更新，新增两张真实 Qt 窗口截图，另外 7 张历史图保持字节。
