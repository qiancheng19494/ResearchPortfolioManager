## 旧版备份兼容与六页流程

## 发现和修复

1. Windows 下对只读打开的文件调用 `os.fsync` 出现 EBADF；材料临时副本改为读写打开再同步，导入、演示和全部涉及材料的流程随后通过。
2. SQLite 的连接上下文只处理提交/回滚，不自动关闭。测试初稿的直接连接未关闭造成 Windows 清理 WinError 32；改用 Store.connection 或 `closing`，再次运行无遗留文件句柄。
3. GUI 后台回调明确使用 Qt QueuedConnection 与 Slot，验证主线程执行和失败后恢复控件。
4. 概览采用单击详情，测试回调显式检查活动对话框并断言真实打开，消除测试初稿定时回调访问空对象问题。
5. 默认配置来源最终统一为实际读取 `config/defaults.json`，定向重开验证通过。
6. 恢复提示原先使用通用 `python` 可能选到未安装 PySide6 的其他环境；改为运行时解释器和入口路径生成且正确转义的 PowerShell 命令。小材料大小显示从四舍五入 0.0 KB 改为实际字节，定向 GUI 流程复查通过。
