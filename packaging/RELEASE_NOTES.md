# ResearchPortfolioManager v1.3.0

本科科研项目与成果档案管理系统 V1.3，修补资料路径与材料输入校验，并增加材料完整性体检；仍为六页本地资料管理。

- 材料页可后台只读检查全部活跃及归档材料，查看异常并导出 JSON 报告。不会自动修复文件或旧哈希。
- 按实际目录位置保护导出目标，统一处理 Windows 目录联接；加强材料路径的设备名、尾点/尾空格、重解析点和硬链接限制。
- 材料类别及版本拒绝空值，防止将 `None` 当文字保存。
- 配置保存使用独立临时文件并同步落盘，完成后原子替换；失败保留上次配置和内存状态，仅清理本次临时文件。
- CSV/HTML 开始新作业时清除旧成功结果，失败不沿用上次成功提示。
- 保留日期日历、任务到期筛选、独立预览、负责人必填及配置类型校验。

数据库 schema 和备份格式仍为 1，不迁移或重建旧库。升级前保存有效备份；恢复仅写新建/空目录，恢复后按提示重启并核对。材料损坏需有效备份或可信原文件恢复，哈希不能重建字节。

本机新增回归先行，继承完整测试随后复跑；Windows 工作流执行回归、打包演示材料大小/SHA-256 校验、EXE 初始化烟测和安装包编译。实际数量和结果见仓库 docs/验证报告.md 与 docs/V1.3发布结果.md，不以历史批次代替。本机界面检查和远端初始化烟测分别记录，安装/卸载向导及打包后的完整手工流程不预填通过。发布文件可与同页 SHA256SUMS.txt 核对，安装程序未作商业代码签名。本轮没有登记提交。
