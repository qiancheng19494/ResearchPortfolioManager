# ResearchPortfolioManager v1.1.0

本科科研项目与成果档案管理系统 V1.1，继续提供原有六页和本地 SQLite 资料管理。

- 项目、任务、成果日期及成果日期范围增加日历选择和清空；空日期、手工输入校验、归档只读保持。
- 任务页增加今天到期、已逾期、未来七天快捷筛选，可叠加关键词、项目和状态。
- 备份恢复增加操作指引、重启命令和本人核对清单；长结果可滚动查看，恢复不覆盖当前资料库。
- 保留独立预览原件保护、负责人必填、统一配置类型校验，以及公开维护版本的安装路径与恢复命令规则。

数据库 schema 和备份格式仍为 1，旧版有效备份继续校验恢复。安装版资料默认位于当前用户的本地应用资料目录；安装文件与资料分离。升级前请保留有效备份，演示数据不能替代真实资料。

本 Release 的安装版和便携版由 Windows 工作流构建，并在发布前执行依赖回归和打包启动烟测。工作流检查与本机完整原生界面回归属于不同验证批次；结果见 Actions 和验证报告。发布后的文件可用随包 SHA256SUMS.txt 核对。安装程序未作商业代码签名。

AI 工具实际参与代码、修订、测试和文档整理。个人贡献、署名和权属依据真实情况确认；本次没有登记提交。
